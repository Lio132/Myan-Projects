# MyanShell
=== Ich garantiere nicht das alles direkt funktioniert === <br>
Um die Abhängigkeiten zu installieren (via WSL) tippe:
```bash
sudo apt update
sudo apt install build-essentials pkg-config libgtk-3-dev libvte-2.91-dev
```
Wenn alles installiert wurde, gehe in das Verzeichnes `./myanShell`
und gebe `gcc -Wall -Wextra -std=c11 msh.c -o msh -lutil` oder
`./compileShell.sh` ein.
